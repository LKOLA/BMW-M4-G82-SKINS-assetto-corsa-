## Installation

1. Place the entire `content/cars/bmw_m4_g82/skins/` folder in your Assetto Corsa installation directory
2. Launch Content Manager
3. Skins will appear under "OEM Colors" group in skin selection
4. All skins are compatible with Custom Showroom
